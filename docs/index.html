ApplyPilot

ApplyPilot is an open-source, self-hosted command-line tool that helps one person run their own job search: it finds job postings, scores them against the user's resume, and writes a tailored resume and cover letter for each one.

Why it asks for Google Drive access

ApplyPilot can save the tailored resume and cover letter PDFs it creates to the user's own Google Drive, in folders by company, role and date, so the user can open them from any device. It requests only the drive.file permission, which lets it see and manage files that ApplyPilot itself created. It cannot see any other files in the user's Drive.

ApplyPilot runs on the user's own computer or server. There is no ApplyPilot service, and no data is sent to the ApplyPilot developers.
