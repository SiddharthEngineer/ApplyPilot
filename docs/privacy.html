ApplyPilot Privacy Policy

Last updated: 2026-10-02

ApplyPilot is an open-source tool that each user installs and runs on their own computer or server.

Google user data

  • What is accessed: only files and folders that ApplyPilot creates in the user's Google Drive (the drive.file scope): tailored resume and cover letter PDFs, and the folders that hold them.
  • How it is used: to upload those files, update them when they are regenerated, download them back when the user applies to a job, and show the user links to them.
  • Where it is stored: the OAuth token and the file links are stored only on the user's own machine. Nothing is sent to the ApplyPilot developers or to any third party.
  • Sharing: Google user data is not shared, sold, or used for advertising or for training AI models.
  • Removal: delete ~/.applypilot/google_token.json, and revoke access at myaccount.google.com/permissions. The files ApplyPilot created stay in the user's Drive until the user deletes them.

ApplyPilot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
